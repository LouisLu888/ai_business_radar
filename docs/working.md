## Lessons Learned

- YouTube 官方字幕下载要求视频编辑权限；第三方内容必须验证独立字幕获取路径。
- 节目介绍不等于逐字稿。只有标题/简介时保留预告，不能伪装为完整摘要。
- 长音频先用有预算限制的异步数据 API，避免第一版同时实现媒体下载、分段和转写基础设施。
- Static Assets 的路由会影响 `ctx.access` 传递，API 认证采用 Access JWT 验证，并测试所有可访问域名。
- 每天检查固定来源和全网发现嘉宾访谈是不同能力，支持范围须在人物页明确展示。
