# 先验证正文获取，再交付可每日阅读的网站

版本 0.2 · 2026-10-08 · 第一轮修订，等待产品 review

建议按下面四个交付阶段推进。第一阶段验证内容是否拿得到、摘要是否可信；其余阶段完成手机阅读、自动日更和 Cloudflare 上线。当前只交付公开仓库与方案，不启动实现或定时任务。

产品行为见 [PRD](prd.md)，工程选择见 [RFC](rfc.md)。

先读 [现成工具与开源项目对比](landscape.md)。现成产品支持自定义摘要，因此本项目优先验证整个阅读流程能省多少手工整理，避免把提示词配置重新包装成产品创新。

## 1. 四个阶段，每阶段都有可检查结果

第一阶段内增加一个限时两小时的现成工具对照，优先 Inoreader。用同一组 20 条样本，比较人物归因、经营数字口径、证据跳转、中文可读性和手工操作时间；再用固定人物名单与时间窗单独检查第三方访谈发现，避免拿预先提供的 URL 测试发现能力。

现成工具若已经满足关键需求，记录其配置步骤与总费用，向产品负责人呈现更轻的选择；当前 Cloudflare 托管约束不自动改变。若试用账号不可用，记录未测试项，继续可独立验证的采集与证据管线，不把注册流程变成长时间阻塞。本轮仅做公开资料调研，尚未运行此对照。

| 交付结果 | 工作与通过条件 | 工作量估计 |
| --- | --- | --- |
| 真实来源能生成可靠中文卡片 | 接收 5–10 人名单；整理来源；取 20 条跨平台样本；验证字幕 API、播客音频、文章正文；达到 PRD 的正文及事实标准，写明各源支持程度 | 1–2 个开发日 |
| 手机上能完成阅读和收藏 | 初始化 TypeScript 全栈项目、D1/R2；实现导入与单条处理；完成简报、详情、人物、收藏及筛选；使用真实样本验证手机阅读 | 2–3 个开发日 |
| 无人值守地每日更新 | 接入频道/节目巡检、YouTube 访谈发现、Cron/Workflows、去重、失败恢复、费用记录；同一已确认 provider job 的故障恢复不重复提交付费任务，列表不重复展示 | 1–2 个开发日 |
| Cloudflare 上线并连续可用 | 恢复 CLI 登录；staging 验证；生产部署与 Access；验证备份恢复、手机访问、七天日更记录 | 约 1 个开发日，另加 7 天观察 |

合计约 5–8 个开发日，是单人实现的初步量级，不是交付日期承诺；API 注册、源站访问问题和 review 等待另计。并行或 AI 辅助可以缩短编码时间，正文可得性仍需实际验证。

第一阶段如果失败，优先解决最大的来源缺口：替换获取服务、登记原作者逐字稿、增加常见访谈节目，或明确接受部分仅链接内容。正式上线前必须得到真实样本结果，不能用假数据界面代替这个判断。

## 2. 费用目标约 30 美元每月，先用免费额度验证

以下价格按 2026-10-08 查询到的官方页面记录，均为美元、税前估算。假设每天 20 条待处理内容，共 600 条/月；每条平均总输入 12,000 tokens、输出 1,500 tokens，已把多步处理算入总量。假设其中 300 次获取已有字幕，另外 600 分钟需要生成转写。

| 项目 | 估算与依据 |
| --- | --- |
| Cloudflare Workers | Paid 方案最低 $5/月，若已有同账号套餐，实际增量可能更低。[官方价格](https://developers.cloudflare.com/workers/platform/pricing/) |
| 工作流与数据 | 此小规模预计落在套餐/免费包含量内，预留 $0–2 波动；账户共享配额需实测。[Workflows](https://developers.cloudflare.com/workflows/reference/pricing/) · [D1](https://developers.cloudflare.com/d1/platform/pricing/) · [R2](https://developers.cloudflare.com/r2/pricing/) |
| 中文模型 | 用 Llama 3.3 70B FP8 Fast 官方输入 $0.293/M、输出 $2.253/M 估算：7.2M 输入 + 0.9M 输出 ≈ $4.14/月。模型变更或长稿多轮处理需重估。[模型价格](https://developers.cloudflare.com/workers-ai/models/llama-3.3-70b-instruct-fp8-fast/) |
| 字幕/转写服务 | Supadata Pro $17/月、3,000 credits；已有字幕每次 1 credit，生成转写每分钟 2 credits。假设用量为 300 + 600×2 = 1,500 credits；其余作为失败恢复与增长余量。[官方价格](https://supadata.ai/pricing) |

合计约 **$26–28/月，建议 $30/月目标预算**。这是基于用量的估算，不是供应商账单上限。域名、新增搜索服务、重度历史回补和其他同账号项目不在此估算内。

技术验证先使用 Supadata 免费 100 credits 和已有 Cloudflare 额度。Basic 的 $5/月为年付价格，不作为无承诺的月付方案。当前不购买或升级任何服务。

费用控制建议：固定来源先做增量和去重；生成转写最多 600 分钟/月，单集不超过 180 分钟；服务 credits 不超过所选套餐，模型费用另设 $5/月初始限额。超出后仍收录链接并排队，第三方自动充值保持关闭。

月度预计总费用按固定订阅 + 已结算变量费用 + 已预留变量费用计算。套餐内 credits 只扣次数，不重复计入美元费用。总费用估计接近 $30 时暂停新增付费工作，在网站标记待处理；平台底费和共享账户的账单不能靠本应用精确封顶。

## 3. 三个依赖要在开发前准备

1. **名单。** 提供 5–10 个优先人物及已知 URL；姓名 + 一个链接即可。能补充追踪理由、经营结果和常见访谈节目更好。参考 [虚构格式示例](../config/people.example.yaml)，真实名单只存私有配置。当前没有提供真实名单，因此来源覆盖和摘要效果仍未验证。
2. **数据服务。** 需要启用 YouTube Data API 的 key；字幕/音频服务需可用凭证。通过本地 secret 或 Wrangler 的安全输入配置，避免提交到仓库。模型通过 Workers AI binding 调用。
3. **Cloudflare。** 已检测本地 Wrangler 4.149.0；`wrangler whoami` 显示登录已过期、无法自动刷新。部署前需重新执行 `wrangler login` 并确认目标账号。无需为本轮文档评审先处理登录。

实施时先复查现有账号和额度。若任何外部服务需要购买，先呈现具体套餐与费用再批准购买；产品 review 本身不代表自动授权所有新订阅。

## 4. Review 时只需要决定这些事

仓库可见性已经确认：**公开 GitHub 仓库**。网站默认是单人私有阅读，公开网站或多用户服务需另行调整产品范围。

| 决策 | 建议默认值 |
| --- | --- |
| 先跟踪谁 | 用户给首批 5–10 人及已知链接；后续逐步增加 |
| 每日阅读节奏 | 美西每天 07:00 前更新，首页最多 5 条重点，其余相关内容保留 |
| 访谈发现范围 | YouTube 每日有限姓名检索 + 已登记 Podcast 节目 + 手动补链；全网播客搜索后续增加 |
| 外部内容 API | 同意由 Cloudflare 后端调用字幕/转写 API，以减少媒体基础设施开发 |
| 支出预期 | 约 $30/月目标；先免费验证，新增付费套餐单独明确确认 |

可以直接在 PRD 上标注修改，或回复具体要调整的默认值。确认产品范围后，第一步是用真实名单做来源验证；本轮停在评审，不开始实现或部署。
